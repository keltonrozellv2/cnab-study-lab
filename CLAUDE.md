# CNAB / CNT Study Lab — working notes for Claude

Owner: SPC Kelton Rozell (keltonrozellv2). A single-file study app for the Army/NSA Computer Network
Assessment Battery (CNAB) and its CNT written section. Served from GitHub Pages as an offline-capable PWA
at https://keltonrozellv2.github.io/cnab-study-lab/ — real users (a Discord beta group) have it open; a bad
push reaches them within minutes.

## Layout
- `src/app.html` — THE source. One HTML file: CSS, markup, and one giant `<script>` (~4,100 lines). Edit this, never `index.html`.
- `src/sw.js.tpl` — service worker template. Its stamped version string is what makes clients show the "Update now" banner.
- `index.html`, `sw.js`, `VERSION` — **built output** at the repo root, served by Pages. Regenerated by `tools/build.sh`; never hand-edit.
- `tools/build.sh <version> [live|dev]` — stamps `__VERSION__` and `__CHANNEL__`. Dev builds go to `dist-dev/`.
- `tools/test.sh [--smoke]` — syntax check + all harnesses (+ Playwright click-through). Run before every build.
- `tools/harness/*.js` — node checks that eval the app script with a DOM stub (`cnt.js` is the stub header); `godmode.js` builds a maxed review profile.
- `tools/smoke.js` — Playwright script exercising first-run flow, keyboard, tests, matrix, import.

## Inside `src/app.html` (search for these names)
- Question sources: `BANK` (214 hand-written items, `{a,f,s,d,q,o,c,w}`), `CONCEPT` (31 shared statics), generators `g*` registered in `GENS`,
  `FACTGEN` true/false fact tables, `SCENARIOS` built from `SCN_NET/SCN_OS/SCN_SEC/SCN_FUND/SCN_PROG/SCN_MORE` via `scnGen(area,cluster)`
  with the `_mk(r,correct,wrongs,{s,q,e})` helper. `CLUSTERS` maps the 34 sub-topics to tags + generators.
- Dealing: `makeDealer` (no-repeat by stem, genShare), `sessionDealer`, `adaptiveDealer` (weights weak sub-topics), `S.retry` spaced second looks.
- Game layer: `gameLoad/gameSave` (state object `X`), `awardXP/awardGold`, `BOSS`/`maybeBoss`/`renderBoss`, chest + loot, `ROAD`/`roadState` sector map,
  `QUEST_POOL`/`WEEK_POOL`, `ACH` achievements, `queueReward/collectReward`, `LEARN` cards, `LABS2` labs, `renderCheat` cheat sheet.
- Transfer: `exportObject`/`importData` (restore semantics — gold etc. are REPLACED, history/weak spots merge), full code `makeProfileCode`
  (deflate+base64url+CRC32, prefix `CNAB1D.`), short code `makeShortCode` (packed varints + base32 + CRC, prefix `CNAB-`, `PC_SECTIONS` picks what travels).
- Storage keys `HIST/WEAK/PREF/XPKEY/NOTEKEY` are prefixed `dev-` when `CHANNEL==="dev"` so a dev site never touches live progress.

## How changes are made
- Patch with small Python scripts (`s.count(old)==1` assert, then replace) or Edit — the file is too big to rewrite.
- After editing: `tools/test.sh` (must print ALL CHECKS PASSED), then `tools/build.sh vNN`, then commit **everything** (src + built output).
- Versions are sequential `vNN` (v55 shipped 2026-10-23). A push to `main` without a new version does nothing for users.

## Content rules (from Kelton — they matter)
- The real CNAB has only a handful of hex/binary items. Keep math minimal: byte-sized hex/binary, simple offsets with round numbers,
  AND/OR/XOR on small values. No octal, no Boolean-algebra simplification, no popcount traces, no odd chmod modes — those were removed on purpose.
- Fundamentals is deliberately light. Windows internals, logs, security recognition, networking judgement are the bulk.
- Write original questions; never copy question dumps from the web. Security scenarios stay at recognition/defensive level — no payloads, no exploit code.
- Watch answer-shape tells: `tools/test.sh` reports "correct-is-longest"; keep it under 25% for every pool. Distractors must be plausible, not silly.
- US spelling. Acronyms keep their case.
- Every sub-topic needs a Learn card (`LEARN`) and the Cheat Sheet should cover what questions ask (SIDs, ports, event IDs, DORA, wildcard masks...).
